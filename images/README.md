# Images

Place your build photos in this folder with the following filenames to match the README links:

| Filename | Section |
|---|---|
| 01-component-placement.jpg | Component Placement |
| 02-wiring-diagram.jpg | Wiring |
| 03-wiring-internal.jpg | Wiring |
| 04-assembly-internals.jpg | Assembly |
| 05-assembly-complete.jpg | Assembly |

To extract images from the Google Doc: File > Download > Web Page (.html, zipped). Images will be in the zip's img/ folder — rename them to match the filenames above.
